# Brandt LandRoller 591A Standalone - Patch notes

## 1.4.1.0 (2026-11-10) - New icon and shop image
- New mod icon and shop picture showing all three versions: Land roller (blue, ring drums), Grass roller (green, spiral drums), Mulcher (orange).
- Shop picture has a clear background.
- Untested in game.

## 1.4.0.0 (2026-11-10) - Ring-roller drums for the Land roller
- Land roller now has black ring-roller drums: fat finned rings alternating with skinny toothed rings, same size as the original drums.
- Grass roller and Mulcher unchanged.
- Untested in game.

## 1.3.0.0 (2026-11-10) - Spiral drums for the Grass roller
- Grass roller now has its own drums with a raised weld bead spiralling the full length (1.80 m per turn), same size as the original drums, rounded ends.
- Land roller and Mulcher unchanged.
- Untested in game.

## 1.2.1.0 (2026-10-31) - Frame colour fix
- Fixed Main colour not changing the frame in the shop (rims already worked).

## 1.2.0.0 (2026-10-31) - Paint options
- Main colour and Rim colour options in the shop for all three versions, full colour palette, no extra cost. Default is the original Brandt blue.

## 1.1.x (2026-10-31) - Mulcher drum fixes
- Fixes to make the mulcher drums show, fit and turn correctly and hide the smooth original drums; original work sound restored.

## 1.1.0.0 (2026-10-31) - First release
- Shop: Rollers. One machine, three tool types: Land roller, Grass roller, Mulcher (bladed drums, mulches while driving unfolded).
- Working width 27.7 m, 275 hp needed, 14 km/h, price 115,000.
