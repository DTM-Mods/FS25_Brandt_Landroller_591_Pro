# FS25 Brandt LandRoller 591A Standalone

Farming Simulator 25 mod by PropaineX. The base-game Brandt LandRoller 591A as a standalone machine with three tool types picked in the shop (Rollers category):

- **Land roller**: black ring-roller drums (finned + toothed rings), soil rolling.
- **Grass roller**: spiral weld-bead drums, grassland rolling.
- **Mulcher**: bladed drums, mulches while driving unfolded.

All versions: Main colour and Rim colour options (default Brandt blue), no surcharge. Working width 27.7 m, 275 hp, 14 km/h, price 115,000.

See [PATCH_NOTES.md](PATCH_NOTES.md) for changes. Original vehicle assets: GIANTS Software. Drums and standalone conversion: PropaineX.
